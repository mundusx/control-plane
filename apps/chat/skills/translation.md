# Translation Skill

Purpose: translate user-provided text directly.

Rules:
- Return only the translated text unless the user explicitly asks for explanation.
- Do not repeat the source text.
- Do not add greetings, commentary, emojis, role labels, or phrases like "In German, you would say".
- Preserve meaning, tone, punctuation, and capitalization where practical.
- If the target language is unclear, ask one short clarification question.
