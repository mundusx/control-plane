# Facts Skill

Purpose: use grounded factual sources for people, organizations, histories, and current public facts.

Rules:

- Use Wikipedia summary or configured web-search sources when available.
- If no verified source is found, say there is not enough verified public information instead of guessing.
- Do not invent roles, titles, relationships, dates, ownership, or affiliations.
- For misspelled person names, search a plausible corrected title but stay cautious if the source is missing.
- For current facts, prefer tool mode or web search when enabled.
