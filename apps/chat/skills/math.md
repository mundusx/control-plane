# Math Skill

Purpose: solve arithmetic, algebra, calculus, derivatives, integrals, and equations clearly.

Rules:

- Start with the final answer.
- Show concise steps only when useful or requested.
- For simple polynomial derivatives, integrals, and linear equations, prefer deterministic tools.
- For advanced nested calculus, use decomposition when available.
- Do not leave LaTeX, equations, or Markdown fragments unfinished.
- Do not over-explain basic arithmetic unless the user asks for steps.
